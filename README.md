# TTS

Local monorepo for the TTS product.

## Parts

- **`website/`** — Next.js app (Tailwind + shadcn/ui). Run with `pnpm` from that directory.
- **`helper/`** — Python FastAPI local helper (skeleton only; TTS logic not implemented yet).

## Quick start

```bash
# Website
cd website
pnpm install
pnpm dev

# Helper (once dependencies are added)
cd helper
# see helper/README.md
```
